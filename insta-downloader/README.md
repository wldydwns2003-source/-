# 📥 원본 화질 다운로더

**인스타그램(릴스·사진 여러 장) · 틱톡 · 유튜브(쇼츠) · 페이스북 · X(트위터) · 스레드 · 핀터레스트** 등
[yt-dlp가 지원하는 1,000개 이상 사이트](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)의 영상을 **원본 화질 그대로** 받습니다.
주소를 **붙여넣는 순간 바로 다운로드**가 시작됩니다.

## 📱 휴대폰에서 쓰기 (무료 클라우드에 올리기, 최초 1회 · 약 10분)
휴대폰에서 바로 쓰려면 프로그램이 인터넷 어딘가에서 돌아가야 합니다. 무료 서비스 **Render**에 올립니다. 휴대폰만으로 가능해요.

1. https://render.com 접속 → **GitHub로 가입/로그인**
2. 상단 **New + → Blueprint** → 이 저장소 선택
   - Branch는 이 프로그램이 있는 브랜치를 선택하세요 (main에 합쳤다면 main)
3. 입력칸이 나오면:
   - `ACCESS_KEY`: 아무 비밀번호 (남이 내 서버를 못 쓰게 막음. 처음 접속할 때 한 번 입력)
   - `IG_COOKIES`: 일단 비워 두기 (아래 '다운로드가 안 될 때' 참고)
4. **Apply** → 3~5분 기다리면 `https://insta-downloader-xxxx.onrender.com` 주소가 생깁니다
5. 휴대폰 브라우저로 그 주소 접속 → 메뉴 → **홈 화면에 추가**

**사용:** 인스타에서 ⋯ → 링크 복사 → 앱 열고 **"붙여넣고 바로 다운로드"** 한 번.
- **안드로이드:** 홈 화면에 추가한 뒤엔 인스타 **공유 → 인스타다운** 만 눌러도 즉시 다운로드
- **아이폰:** 받은 후 **"갤러리(사진)에 저장"** → "동영상 저장" 하면 사진 앱에 들어갑니다

> 무료 플랜은 15분간 접속이 없으면 잠들어서 깨우는 데 30~60초가 걸립니다. 그래서 서버가 10분마다 스스로 접속해 항상 깨어 있게 해 두었습니다.
> (무료 750시간/월 안에서 서버 1개를 24시간 켜 둘 수 있어요. Render에 다른 무료 서버를 또 만들면 시간이 모자랄 수 있습니다.)

## 💻 PC에서 쓰기 (Windows)
1. [Python](https://www.python.org/downloads/) 설치 — 설치 화면에서 **"Add python.exe to PATH"** 체크
2. 이 `insta-downloader` 폴더에서 **`run.bat` 더블클릭**
   - 처음 한 번만 필요한 프로그램을 자동 설치합니다 (1~2분)
3. 브라우저가 자동으로 열리면 (`http://127.0.0.1:5000`) 인스타 주소를 붙여넣기 → 끝

Mac/Linux: `./run.sh`

## 화질
- 해상도가 가장 높은 것을 고르고, 같은 해상도면 휴대폰·캡컷과 호환이 좋은 H.264를 우선합니다.
- **영상:** 인스타 서버에 있는 가장 높은 화질의 영상과 음성을 받아 mp4로 **합치기만** 합니다 (재인코딩 없음 → 화질 손실 없음).
  ffmpeg는 자동으로 같이 설치됩니다.
- **사진:** 인스타가 제공하는 최대 해상도 원본을 그대로 저장합니다.
- **여러 장 게시물:** 무압축 zip 하나로 묶어서 받습니다.

## 다운로드가 안 될 때 (로그인 요구 / 비공개 계정 / 요청 제한)
인스타가 로그인 안 된 요청을 막는 경우가 있습니다. 내 로그인 쿠키를 넣어 주면 해결됩니다.
1. 크롬 확장 프로그램 **"Get cookies.txt LOCALLY"** 설치
2. instagram.com에 로그인한 상태에서 확장 아이콘 → **Export** (Netscape 형식)
3. **PC:** 받은 파일 이름을 `cookies.txt`로 바꿔 이 폴더(`app.py` 옆)에 넣기 → 프로그램 다시 실행
   **클라우드(Render):** 서비스 → Environment → `IG_COOKIES` 값에 파일 내용 전체를 붙여넣기 → Save (자동 재시작)

> 클라우드 서버는 인스타가 로그인 없는 접속을 더 자주 막습니다. 안 되면 `IG_COOKIES`를 꼭 넣으세요.
> 다운로드 전용 **부계정** 쿠키를 쓰는 걸 추천합니다.

> ⚠️ `cookies.txt`는 내 계정 로그인 정보입니다. 남에게 주거나 GitHub에 올리지 마세요 (`.gitignore`에 이미 제외되어 있음).

인스타 구조가 바뀌어 갑자기 안 되면 `run.bat`을 다시 실행하세요 (클라우드는 Render에서 **Manual Deploy → Restart**) — 실행할 때마다 다운로드 엔진(yt-dlp)을 최신으로 업데이트합니다.

## 틱톡 화질 올리기 (선택)
틱톡 웹은 로그인하지 않으면 720p까지만 주는 경우가 많습니다. 내 틱톡 계정으로 로그인한 상태로 받으면 더 높은 화질이 나올 수 있어요.
1. PC 크롬에서 tiktok.com 로그인 → F12 → Application → Cookies → `https://www.tiktok.com` → **`sessionid`** 값 복사
2. Render → 서비스 → Environment → Add → Key `TT_SESSIONID`, Value 복사한 값 → Save
- 다운로드가 끝나면 화면에 **화질(예: 1080×1920)**이 표시되니 바로 확인할 수 있어요.
- 로그인해도 영상에 따라 720p가 최고일 수 있습니다.
