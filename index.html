해시태그를 클릭하면 틱톡/인스타 검색 페이지가 새 탭으로 열립니다. (로그인 상태의 브라우저에서 사용하세요) 조회수 숫자로 정렬해 보려면 자동 수집 탭을 쓰세요.

페이지 안에서 국가(한국/미국 등)·기간·업종을 바꿔 볼 수 있어요.
Apify API로 게시물을 수집해서 조회수 · 바이럴 배수(조회수÷팔로워) 순으로 정렬합니다. 처음이라면 설정에서 API 토큰을 먼저 넣어주세요.
1) apify.com 무료 가입 (매달 무료 크레딧 제공)
2) Console → Settings → API & Integrations 에서 Personal API token 복사 → 위에 붙여넣기
토큰은 이 브라우저에만 저장되고, Apify 외 다른 곳으로 전송되지 않습니다.
