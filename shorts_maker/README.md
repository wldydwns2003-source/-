# 🎬 원본으로 쇼츠 자동 제작기 (Windows)

해외 원본 영상 하나를 넣으면 **대본 → 타입캐스트 나레이션 → 컷 편집(확대·크롭·속도·색감) → 자막 → 상단 후킹 문구 → 제목·설명**까지 자동으로 만들어 1분짜리 이야기 쇼츠를 완성합니다.

## 처음 한 번만: 설치
1. 이 `shorts_maker` 폴더를 내 컴퓨터에 받아 둡니다.
2. **`설치하기.bat`** 을 더블클릭합니다. 파이썬, ffmpeg, 필요한 프로그램이 설치돼요.
3. 메모장이 열리면 API 키 두 개를 붙여넣고 저장합니다.
   - `ANTHROPIC_API_KEY`: https://console.anthropic.com → API Keys 에서 발급
   - `TYPECAST_API_KEY`: 타입캐스트 API 콘솔에서 발급
4. **`목소리목록.bat`** 을 더블클릭해서 쓸 목소리의 ID 를 찾고,
   `presets\default.json` 의 `"typecast_voice_id": ""` 따옴표 안에 넣습니다.

## 쇼츠 만들기
- **`쇼츠만들기.bat`** 아이콘 위로 원본 영상(mp4)을 끌어다 놓습니다. 여러 개를 한꺼번에 놓아도 됩니다.
- 대본을 먼저 보고 고치고 싶다면 **`대본확인하고만들기.bat`** 위로 끌어다 놓으세요. 메모장에 대본이 열리고, 고쳐서 저장한 뒤 Enter 를 누르면 계속 만듭니다.
- 완성되면 `완성` 폴더가 열립니다.
  - `날짜_제목.mp4`: 업로드할 쇼츠
  - `날짜_제목.txt`: 제목, 설명, 해시태그, 대본

## 내 채널 스타일로 바꾸기
`presets\default.json` 을 메모장으로 열어 값만 바꾸면 됩니다.

| 항목 | 설명 |
|---|---|
| `script_style` | 채널 주제나 말투. 예: `"동물 채널, 따뜻하고 귀여운 말투"` |
| `target_seconds` | 목표 길이(초) |
| `voice_speed` | 말 빠르기 (1.0 = 보통) |
| `typecast_model` | 타입캐스트 모델 이름 |
| `layout` | `center` (가운데 영상 + 위아래 글자) 또는 `fill` (화면 꽉 채우기) |
| `background` | `blur` (흐린 배경) 또는 `black` (검은 배경) |
| `font_name` / `font_file` | 글꼴 이름, 또는 .ttf 파일 경로 |
| `hook_color1`, `hook_color2` | 상단 문구 첫째·둘째 줄 색 |
| `subtitle_size`, `subtitle_color` | 자막 크기와 색 |
| `original_volume` | 원본 소리 크기 (0 = 끄기) |
| `bgm_file`, `bgm_volume` | 배경음 파일과 크기 |
| `transition_sfx_file` | 장면이 바뀔 때 넣을 효과음 파일 |
| `mirror` | 좌우 반전 |

설정을 여러 개 두고 싶으면 `default.json` 을 복사해서 `동물.json` 처럼 저장하고,
명령창에서 `py make_short.py 원본.mp4 --preset 동물` 로 실행합니다.
새 파일에는 바꾸고 싶은 값만 적어도 됩니다. 나머지는 기본값을 씁니다.

## 문제가 생기면
- **"ffmpeg 가 설치되어 있지 않아요"**: 설치 후 컴퓨터를 다시 켜 주세요.
- **"타입캐스트 오류 (4xx)"**: 키, voice_id, `typecast_model` 값을 확인하세요. 오류 메시지를 그대로 보여주면 고쳐 드릴게요.
- **API 없이 편집만 시험해 보기**: `py make_short.py 원본.mp4 --mock`

## 참고
- 영상 한 편에 Claude 사용료(장면 분석 + 대본 작성)와 타입캐스트 사용량이 듭니다.
- 원본을 잘라 쓰고 확대, 색감, 나레이션으로 재구성하지만, 저작권 클레임이 절대 걸리지 않는다는 보장은 없어요. 원본 선택은 신중하게 해 주세요.
